A Streamlit-based web application that predicts daily flood risk levels (Low, Medium, High) for the Maribyrnong City Council, Victoria, using real-time and forecast weather data from the Visual Crossing API. The app trains a Long Short-Term Memory (LSTM) neural network on historical weather (January 2015 to June 2025) and flood risk data to estimate the likelihood of flooding for today and the coming days. It features an interactive dashboard displaying key weather attributes, daily forecasts, and risk levels to support early warning and disaster preparedness efforts.
